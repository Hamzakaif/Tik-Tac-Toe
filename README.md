# Tik-Tac-Toe

A fully functional Tic Tac Toe game built with HTML, CSS, and JavaScript.

## How to Use

1. **Open the Game**: Open `index.html` in your web browser
2. **Gameplay**: 
   - Click on any empty box to make your move (You are X)
   - The Second player  play as O
   - First player to get 3 in a row (horizontally, vertically, or diagonally) wins
3. **Winning**: 
   - If you get 3 X's in a row, you win!
   - If the Second Player gets 3 O's in a row, the Second Player wins
   - If all boxes are filled with no winner, it's a draw
4. **Reset Game**: Click the "Reset" button to start a new game

## Features

- Interactive gameplay against Your friends
- Simple and clean user interface
- Real-time game status updates
- Responsive design

## Files

- `index.html` - Main HTML file
- `style.css` - Styling for the game
- `app.js` - Game logic and functionality

## Installation

No installation needed! Just open `index.html` in your browser to play.
